# Clippings 원천 처리

SCHEMA.md의 외부 원천이다. 단일 파일 외에 폴더 또는 미처리 전체 요청도 받는다.

1. `python3 -B scripts/clippings_todo.py --all`로 목록을 읽고 기존 검토 상태와 대조한다. 처리됨은 정식 페이지가 그 클리핑을 줄 인용한 것, 건너뜀은 작업 공간 excluded.jsonl에 사용자 제외 결정이 있는 것이다. 정상 접근한 빈 폴더만 0건이다. 접근 오류는 미확인으로 보고한다. 지정 범위 전체를 검토하고 임의의 건수 제한을 두지 않는다.
2. frontmatter의 제목·원 URL·저자·발행일과 본문의 하이라이트·메모를 읽는다. 외부 주장을 조직의 채택 지식으로 바꾸지 않는다.
3. 클리핑 요약 페이지를 만들지 않는다. 조직이 채택하기로 한 주장만 관련 concept·policy 문장 옆에 로컬 사본의 줄 인용으로 넣고 sources에도 남긴다. 채택 여부가 불분명하면 위키 변경이 아니라 채택 판단 질문으로 올린다. 클리핑 한 건만으로 entity를 만들지 않는다.
4. 나머지 합성과 검토는 ingest와 review의 공통 절차를 사용한다. 제외 후보도 이유와 함께 묶어 질문한다. 사용자 제외 결정 후에만 작업 공간 excluded.jsonl에 한 줄을 추가한다: `{"path": "<Clippings 기준 상대경로>", "reason": "...", "evidence": "^[/claude-sessions/…:줄]", "at": "ISO 시각"}`. 이미 만든 검토 버전에는 rejected도 기록한다.
5. 조사 결과는 그 배치의 inventory.json에 처리·제외·대기 건수와 대상을 남긴다. 초안만 준비한 경우 처리로 세지 않는다. 처리 수는 정식 페이지의 인용, 제외 수는 사용자 결정, 대기 수는 실제 대기 목록에 대조한다.

자동 검사는 접근 가능성·파일/인용·실제 반영 여부를 확인한다. 사람은 외부 주장의 채택·제외와 위키 맥락에 연결하는 해석을 판단한다.
